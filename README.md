# PRII - Potential Road Impact Index
This repository is a part of a Master Thesis project titled "Assessing Potential Impact of Road Expansion on Threatened mammal habitats in the Congo Basin". It will likely be consolidated using either R or Python. A license and a data_source script contain information on the reusability of the code provided in this repository, as well as crediting the authors of data used. The aim of the project is to develop a spatially applicable index which will give a "Potential Road Impact" score to each road network opened during the recent (2019-2025) road expansion.
